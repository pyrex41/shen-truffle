# Shen 41.2 canonical tests

These tests are vendored from the Tarver S41.2 refresh used by `shen-go` and
`shen-lua` (mirror commit `11fc51b`, tag `s41.2-pristine-20260711`). The suite
is the upstream `Kernel/tests` corpus, including extension fixtures; filenames
and test data are retained for runner compatibility.

The kernel and standard-library licensing terms are included under
`src/main/resources/LICENSE.txt` and `src/main/resources/stlib/LICENSE`.
